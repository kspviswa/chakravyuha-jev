What do these numbers mean?
  • Speed — totalMs is the whole-run wall time; msPerStep = totalMs ÷ max(steps, 1). Lower is better.
  • Optimality — optimalSteps / steps on the grid skin, optimalCost / cost on the navigation skin, clamped to [0, 1]. 1.0 is perfect. A run that did not reach the goal scores 0; a board with no route at all scores null and is excluded from the mean rather than counted as 0.
  • Accuracy — checksPassed / checksTotal from the referee's verification checks. reached is tracked separately, because “valid but never arrived” and “arrived” are different failures.
  • Variance / stddev — sample variance (n − 1 denominator). Variance needs at least two runs; below that it shows —, never a false 0.
  • Groups are source · mode · skin. Different kinds of run are never averaged together — stub runs are near-perfect by construction.
